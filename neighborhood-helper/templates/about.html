About Neighborhood Helper

Connecting neighborhood households with trusted local service professionals.

Project Overview

Neighborhood Helper is a realistic, human-designed web application developed as a college mini project. It solves the everyday difficulty of finding reliable, nearby household technicians such as plumbers, electricians, carpenters, painters, and appliance mechanics.

Unlike bloated commercial platforms with hidden commissions and opaque pricing, Neighborhood Helper focuses on:

  • Location-first discovery: Accurately calculating real distances using the Haversine spherical distance formula.
  • Balanced helper sorting: Evaluating both proximity and user satisfaction ratings.
  • Strict workflow integrity: Enforcing a transparent booking lifecycle (Pending → Accepted → In Progress → Completed → Rated) for reliable service delivery.
  • Verified community reviews: Ratings and comments are enabled only after the helper completes the requested service, ensuring authentic neighbor feedback.

Technical Architecture:

Frontend: HTML5, CSS3, Vanilla JS
Backend: Python, Flask
Database: MySQL 8.0 (PyMySQL)
Security: Password Hashing (scrypt), Parameterized Queries, Role-Based Session Protection
